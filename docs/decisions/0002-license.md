# 0002: License

## Context

The repository is public. The maintainer may want to sell the app, and an open-source license, once granted, cannot be taken back.

## Decision

All rights reserved (see `LICENSE`): the repository is published for reference only. Dependencies must use permissive licenses (MIT, BSD, Apache-2.0, or similar) that allow a commercial, closed-source app, each listed in `THIRD_PARTY.md`. Nothing under copyleft terms.

## Consequences

No open-source license, contributing guide, or wording that invites outside contributions is added. The maintainer may open-source the project later.
