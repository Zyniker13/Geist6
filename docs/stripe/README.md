# Stripe Research Notes

Written in milestone M0 (see `ROADMAP.md`), from Stripe's documentation as of
2026-11-16 against API version 2026-10-28.endive (spec release v2600), each in
our own words with its sources listed:

- `api-inventory.md`, `coverage-matrix.md`, `api-inventory.json` — generated by
  `Tools/inventory` from the pinned spec; regenerate with
  `swift run inventory gen`, check with `swift run inventory check`.
- `access.md` — every way the app could get access to an account, and the choice (decision 0003).
- `permissions.md` — restricted-key permissions and the Dashboard and Management sets.
- `limits.md` — rate limits, page sizes, search, events retention, file sizes, metadata and expansion bounds.
- `versioning.md` — the pinned version, `Stripe-Version`, and the upgrade policy (decision 0004).
- `events.md` — snapshot and thin events, why a serverless client polls the Events API.
- `brand.md` — Stripe's Marks Usage Terms applied to the app's name and wording, and the candidate names (decision 0006).
