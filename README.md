# Geist6

A native iPad app for one or more Stripe accounts: a clear dashboard for anyone who needs to see what is happening, and a full management interface for anyone allowed to act. It connects directly to the Stripe API with the user's own restricted key, with no server in between, and aims to cover every part of Stripe that a client app can reach.

"Geist6" is a working name. This project is not affiliated with or endorsed by Stripe.
